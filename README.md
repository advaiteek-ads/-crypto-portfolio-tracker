# Crypto Portfolio Simulator
 
Live demo: https://advaiteek-ads.github.io/-crypto-portfolio-tracker/
 
Track real-time crypto prices (CoinGecko API) and simulate what past investments would be worth today.
 
## Features
- Live prices with 60-second auto-refresh
- Purchase dates: leave the buy price empty to auto-fill the historical price for that day
- Currency switcher: USD, INR, EUR, GBP
- Allocation doughnut chart by current value
- Portfolio value vs amount invested over 1D / 7D / 30D / 90D / 1Y
- Profit/loss in currency and %
- Caching, retries and saved data to handle API rate limits
- Data saved in the browser (localStorage)
## Tech
HTML, CSS, vanilla JavaScript, CoinGecko API, Chart.js, GitHub Pages
 
For learning only, not financial advice.
