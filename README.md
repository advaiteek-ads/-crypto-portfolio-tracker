# Crypto Portfolio Tracker

Tracks live crypto prices (CoinGecko API) and shows profit/loss for your portfolio, with a historical trend chart.

## Features
- Add holdings: coin, amount, buy price
- Live prices, auto-refresh every 60 seconds
- Current vs initial value, P&L in $ and %
- 1D / 7D / 30D / 90D portfolio trend (Chart.js)
- Data saved in the browser (localStorage)

## Run
Open `index.html` in any modern browser, or use the GitHub Pages link.

## Tech
HTML, CSS, JavaScript, CoinGecko API, Chart.js
